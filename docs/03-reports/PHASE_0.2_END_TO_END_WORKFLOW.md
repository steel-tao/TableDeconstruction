## 一、任务概述

实现并验证完整的 end-to-end 工作流，演示从 Obsidian Vault 到 WeChat 发布的完整链路。

## 二、交付物

### 1. 工作流演示脚本 (`src/e2e-workflow.js`)

交互式演示脚本，引导用户完成从文章选择到发布准备的全流程。

#### 脚本流程

```
步骤 1️⃣  → 欢迎信息
        ↓
步骤 2️⃣  → 扫描 Obsidian Vault
        ↓
步骤 3️⃣  → 选择要发布的文章
        ↓
步骤 4️⃣  → 验证文章信息
        ↓
步骤 5️⃣  → 准备 Doocs 格式
        ↓
步骤 6️⃣  → 显示发布预览
        ↓
步骤 7️⃣  → 生成工作总结
```

#### 用户交互特性

- ✅ 彩色终端输出（Unicode 图标和符号）
- ✅ 进度条显示扫描进度
- ✅ 按系列分组显示文章
- ✅ 交互式文章选择
- ✅ 确认对话框
- ✅ 自动导出结果

### 2. NPM 脚本添加

```json
"workflow:demo": "node src/e2e-workflow.js",
"workflow:start": "node src/e2e-workflow.js"
```

用户可以快速启动：
```bash
npm run workflow:demo
# 或
npm run workflow:start
```

         ↓

   ├─ 粘贴到微信后台
